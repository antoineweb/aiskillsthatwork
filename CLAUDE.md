# Publishing rules for this repository

Everything in this repository is public: the skills, the site, the downloads and the commit history.

## Privacy check before every publish

A skill kept privately in Claude may contain private data. A skill published here must not. Before adding or updating anything in this repository, read every changed file in full and remove:

- Client and employer names, their products, internal tools, internal URLs and project code names.
- Client logos, screenshots or videos of client work, unless the owner has agreed in writing.
- Real people's names, emails, phone numbers and addresses. Use fictitious demo data.
- API keys, tokens, key IDs, passwords and paths to credential files.
- Server names, hostnames, IP addresses and database names of private infrastructure.
- Local file paths from a personal machine.
- Personal preferences, notes or business rules that only make sense for the author.
- Colours, wording or assets taken from a client's design system.

Then:

1. Replace what was removed with a neutral, fictional example or a clearly named setting the user fills in.
2. Rebuild any download zip from the cleaned files, never from the private copy.
3. Search the changed files and the zip for the removed terms and confirm there are no matches.
4. Tell the author what was removed, and anything you were unsure about, before pushing.

If in doubt about one item, leave it out and ask.

## Commits

Use the author's GitHub noreply address for commits, not a personal email address.

## Writing

Published text is in English and never uses em dashes.
